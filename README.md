# Tutorial for generating Model Card

NOTE: `chap generate-modelcard` currently only works with NetCDF evaluations produced by `chap evaluate2`.

## Example using minimalist_example model

Evaluate the minimalist_example using the command below:

```sh
chap evaluate2 \
  --model-name https://github.com/dhis2-chap/minimalist_example \
  --dataset-csv ./example_data/vietnam_monthly.csv \
  --output-file ./eval.nc
```

This will generate a NetCDF file containing the evaluation results in the root directory .´/eval.nc´, use the output file location as the first argument to the generate-modelcard function:

A run directory is also created under `./runs/` (default is timestamped).

Remember to replace the timestamp with your latest timestamp.

```sh
chap generate-modelcard ./eval.nc ./runs/minimalist_example/<timestamp>
```

On completion a pdf file **modelcard_test.pdf** containing the Model Card should have been generated in the root directory.

## Generating a Model Card from an existing evaluation


After running evaluate2, a folder `runs/model_name/<timestamp>` should also have been generated that contains copy of your model directory along with data files used.

Run the following command in the CLI:

```sh
chap generate-modelcard \
--evaluation-path <Path to NetCDF file generated by evaluate2> \
--run-path <Path to runs/model_name/timestamp>
```
